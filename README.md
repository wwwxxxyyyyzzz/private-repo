# 共振野境 RMS — Homepage preview

Buildless, responsive brand homepage. Source and deployable static assets are in `dist/`.

## Run

```sh
npm run dev
```

Open http://localhost:5173. No dependencies or build step are required. `npm run check` checks JavaScript syntax.

## Implemented

- PDF-based color tokens in `dist/css/style.css`.
- Responsive homepage, mobile navigation, keyboard controls, reduced motion.
- Hero particle interaction, four-stage sticky story, species detail dialogs.
- Interactive Chladni-inspired canvas, complexity adjustment, reset, transparent PNG export.
- Opt-in synthetic ambience. No automatic audio playback or wildlife recording claims.

This is the homepage preview only. The full audio archive, uploaded-audio analysis, and product hotspot pages are not implemented in this milestone.

## Asset sources

All photography, product illustrations and the original RMS mark were extracted from the two PDFs supplied in the conversation. No stock images or generated replacement animals were added. Embedded source watermarks are preserved. The hero uses the PDF's masked version of the black gibbon reference provided in chat. Existing species labels remain editorial placeholders and should be verified before the full species archive is published.

The mathematical resonance fields are generative illustrations inspired by Chladni patterns, not physical simulations or scientific measurements. The audio toggle uses explicitly labeled, browser-generated tones rather than real animal recordings.
